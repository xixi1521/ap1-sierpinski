# AP1 · 交互式 2D 分形 —— Sierpinski 垫片

课程：计算机图形学实践（2026 秋） · 教材：Angel & Shreiner, *Interactive Computer Graphics*, 8th ed.

技术栈：原生 WebGL 2.0 + JavaScript；`index.html` + `gasket.js`；
`initShaders` 为教材 `Common/initShaders.js` 的自行等价重写。

## 运行方式

直接打开网页即可，无需本地服务器。

## 两种生成算法原理

### 1. 混沌游戏（Chaos Game）

从三角形内部任意一点出发，每一步随机选一个三角形顶点，将当前点向该顶点移动一半距离。重复足够多次后，点的集合自动收敛成 Sierpinski 垫片。

核心公式：`p_{n+1} = (p_n + V_random) / 2`

默认生成 5000 个点（可调至 20000），以 `gl.POINTS` 渲染，支持"逐点生长"动画。

### 2. 递归细分（Recursive Subdivision）

从大三角形开始，递归地将每个三角形细分为四个小三角形，去掉中间倒三角形，保留三个角上的小三角形。深度 0–6 可调。

同一组数据支持三种渲染模式：点云（POINTS）/ 线框（LINES）/ 实体（TRIANGLES）。

## 交互操作说明

| 操作 | 效果 |
|---|---|
| 鼠标左键拖动 | 平移画布 |
| 鼠标滚轮 | 以光标为中心缩放 |
| 数字键 1 | 混沌游戏-点云模式 |
| 数字键 2 | 递归细分-线框模式 |
| 数字键 3 | 递归细分-实体模式 |
| 空格键 | 暂停/继续逐点生长动画（仅混沌模式） |

参数面板可调：顶点数、递归深度、点大小、4 套配色方案。
